# 陪读小猫

学习作品中的轻量陪读入口；不会改动作品或个人学习偏好。

- 角落入口讨论整篇，图文段落的“没看懂？”带入服务端验证的章节与段落编号。
- 快捷提问：讲简单点、换个例子；支持自由输入。
- 当前文章原文、目标章节和最近 8 条对话作为回答上下文；例子需标记虚构，引用逐字匹配原文后才提供跳转按钮。
- 使用现有原文窗口定位、高亮。对话单独保存在 companion_chats 表，每篇保留最近 40 条，不迁移或修改原有记录。
- 会话沿用作品所有权检查；每用户同一时间一个请求，全局四个；每日每用户 60 次、全局 600 次。
- 猫咪入口目前是 emoji 与轻微 CSS 动效，不是定制绘制的角色；沿用关闭动效设置，可缩小入口。不主动弹消息。

验证：类型检查、构建、模型接口与来源校验测试、原有 HTTP 隔离测试、78 项模拟浏览器检查通过；真实模型对合成测试原文回答并返回有效引用。并非对所有主题的学习效果或回答正确性作出保证。

本次不包括公共静态历史案例页面的助手、不包括桌面常驻宠物、选中文字自动捕获或全量永久聊天档案。
