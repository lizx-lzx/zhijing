# 整个平台 UI 更新与验收

2026-09-08。用户明确纠正范围：要改的是整个平台，不是只优化《窗口期可能只剩五年》的单篇演示。

## 本次范围

主站 `/zhijing/` 的欢迎页、8 题问卷、个人学习 Skill、文章输入工作台、生成进度、失败与部分完成状态、私人学习库、通用学习作品阅读器、原文弹窗与恢复入口。

保留一次问卷 → 确认保存 Skill → 输入文章 → 生成与学习的流程；不重写后端提示词、数据库、用户画像、作品内容或媒体文件。单篇 OpenMAIC 风格试作继续独立存在，首页只把它标明为示例作品，不伪装成当前用户的实时产物。

## 设计与交互

- 浅灰蓝底、白色内容面、深蓝文字与靛蓝主操作，统一文字、留白、边框与按钮。正文一般 16—17px，必要辅助信息保留可读对比度，删除重复介绍。
- 已建档用户：电脑端固定侧栏，手机端底部导航。开始学习、学习库、我的学法始终可达；原来保存与恢复的能力保留。
- 问卷显示总题数、用时、随时可改；三组可跳转；上一步、多选和辅助形式保持。未新增必答测验。
- Skill 先展示形式、入口、节奏，逐条规则按需展开；只在用户点击保存后更新长期规则。重做问卷与下载移出手机端吸底主操作区。
- 工作台突出输入和生成；临时调整直接展开原设置，仍然只影响当前作品。输入方式、失败后的正文回退、文件导入、来源和 AI 处理说明保留。
- 学习库使用一致卡片，区分制作中、已完成、部分完成、失败与学完状态。空库直接引导添加第一篇。
- 学习作品工具栏吸顶；手机目录用原生弹窗，切换章节时对视频 / 音频按真实场景时间定位，图文按章节滚动。视频与音频切换暂停旧播放器。配套图文默认折叠，原文来源和可选练习不删除。
- 弹窗关闭恢复触发按钮焦点、锁定背景滚动；减少动态效果。复用现有 ReactBits StaggeredText，仅在欢迎标题使用轻微过渡，不新增依赖或授权配置。

## 本地验收

`npm test`：19 项核心 / HTTP 测试、类型检查、ESLint、生产构建及 1 项生产 HTML 测试。

`scripts/ui-acceptance.mjs` 使用独立浏览器上下文和明确标注的测试接口数据，不访问用户已有会话、不触发供应商费用、不作为学习有效性的证明。测试视频资源复用已生成的文章媒体，仅验证播放器和章节切换。

已跑通完整 UI 流程，包括欢迎页、单选 / 多选题、首次 / 已有 Skill、空 / 非空工作台与学习库、生成中、四种学习形式、失败与部分完成。320、390、768、1024、1440px 视口，以及 390px 下根字号放大到 200% 未出现页面横向溢出。手机结果是桌面 Chromium 视口模拟，不冒充真实手机验收。

行为检查包含：上一步保留答案、附加形式保留、未保存编辑不提交、生成后可返回学习库、视频真实时间跳转、原文弹窗 Escape 与焦点恢复、手机目录定位、失败可重试、部分失败可先看图文。记录为 73 条布局 / 行为结果，截图和报告在被忽略的 `test-results/platform-ui/`。

## 发布边界

仅发布到用户自有服务器的主站。新前端版本使用已有兼容的依赖，保留当前已发布的 demo 目录和旧哈希资源。数据与私有配置在版本目录之外。

`deploy/activate-ui.sh` 要求明确的新版本路径及预期旧版本，核对依赖锁文件与构建结果后才切换 `current`；只重启网页服务，不重启 API、不修改 Nginx、TLS 或其他站点。健康检查失败自动恢复旧前端版本。

实际公网发布结果在完成后补记；本节不把本地构建通过称为已经上线。
