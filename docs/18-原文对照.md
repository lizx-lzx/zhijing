# 原文对照 · 2026-09-13

图文每章的「查看对应原文」保留完整导入文本和前后文，自动滚动到来源段落。多段来源提供上一处、下一处。关闭或返回讲解后保留阅读位置。

高亮边界：只在已有来源段落中查找讲解文字的字面对应，匹配的句子标黄；没有可靠字面对应时，浅色标记整段并注明「未精确到句」。不把语义猜测当成精确引用，不修改生成内容、学习 Skill 或旧作品数据。无效来源 ID 显示完整已保存原文，不呈现空白。

公开知乎案例保留必要的原段落摘录，在段落内高亮已核对的短引，并提供作者原文链接。没有把全文加入公开包；文本片段链接能否在知乎定位受浏览器和知乎页面限制，本地高亮不依赖它。十处原段落与用户提供文件逐项比对一致。

验证：主站类型和 6 项渲染测试通过；隔离浏览器验收通过（包括前后文保留、句子与段落高亮、多处切换、手机返回和 Escape 返回焦点）；案例 22 项测试通过、1 项媒体测试跳过。没有重新生成或覆盖视频。前端独立发布，API 和私人数据不变。
