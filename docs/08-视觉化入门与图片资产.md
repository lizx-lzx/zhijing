# 视觉化入门与图片资产

2026-09-08：用户希望增加图片、不只靠文字，紧接着“从 0 体验”的需求。本次改动聚焦真实主站的欢迎页、问卷、个人学法、工作台与学习库，不改动来源处理、模型、问卷维度、个人数据和媒体生成逻辑。

## 产品变化

- 欢迎页用一张纸带转化为视频、图文与听读的插画，压缩原来大块案例说明，保留真实历史案例入口。
- 问卷的形式、讲解入口与节奏选项配上静态示意。示意不是播放按钮，不自动播放、不增加提问、不给用户贴能力标签；原来的 8 题、回退、多选与保存确认不变。
- 个人学法与工作台显示所选形式的呈现示意。学习库优先显示本人作品的真实视频封面；没有封面时使用通用插画，绝不用“平均数”的示例冒充其他文章内容。
- 首页可通过 `?start=welcome` 打开；点左上角“知径”也回到欢迎页。已有访客可以用空白默认答卷重新体验，或直接继续原来的学习。查看、选题不改保存的学法，仍需明确点击保存；不会清空作品或更换会话。
- 图片保留固定尺寸；网页使用约 49 KB 的 WebP，原 PNG 一并保留。小屏采用折行和单列布局，视觉示意不取代选项的文字名称。
