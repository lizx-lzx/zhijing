# 页面动效

2026-09-08：用户表示更喜欢动效。本次将动效接入知径现有首页、问卷和作品卡片，不重新生成内容、修改学习 Skill 或更换插画。

- 已安装的 ReactBits StaggeredText：两行标题依次上移归位，正文始终可见。
- 首页：插画轻浮动、桌面鼠标轻视差，说明与步骤渐次出现。
- 问卷：题目过渡、选项错峰进入、悬停抬升、按下回弹与选中反馈，进度条平滑变化。
- 形式示意：听读波形轻动、图表柱形展开、网页节点依次强调。均是问卷呈现示意，不代表真实媒体正在播放。
- 学习库：封面卡片悬停反馈，手机不依赖悬停操作。
- 页面提供“暂停动效”。跟随系统减少动态效果，后台标签页停止页面效果；不暂停真实视频和音频。开关仅影响当前页面展示，不写入长期学法或账号数据。

沿用现有 ReactBits 和已安装的 motion，不新增 registry 安装、付费素材、WebGL、逐帧 JS 循环或浏览器依赖。主体动效使用 CSS 的 transform / opacity；视差只在鼠标实际移动时更新。

本轮验收范围为组件渲染、开关逻辑、减少动态样式、类型、构建与公网资源。未执行浏览器交互或截图验收，不以工程测试冒充动效观感验证。
