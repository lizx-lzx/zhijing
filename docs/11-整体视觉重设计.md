# 整体视觉重设计 · 2026-09-08

用户要求知径作为完整作品呈现，重新设计整个主产品 UI，并真正移除无用小字。此版取代此前固定侧栏、浅紫圆角卡片和首页纸带插画主视觉，不改变生成系统或个人学习规则。

## 设计与范围

- 冷白、墨黑、钴蓝共用色彩变量；大标题使用中文衬线字体栈，正文仍为无衬线。衬线字形随设备字体而异，没有新增字体下载。
- 首页保留一句主张、一句功能说明、主按钮和题数时间。删除三步流程条、重复的返回提醒和非作品页的 AI 通用脚注。首页主图改为实际作品截图，明确标为示例；不是新生成结果。
- 全部主产品页面采用顶部导航；移除桌面固定侧栏及手机固定底栏。手机导航可换行，不遮挡问卷操作。
- 问卷移除外层卡片，保留直观示意、分组、题数、返回、可多选和必要解释。个人学法摘要改为开放式分栏；完整规则仍可展开，明确保存才生效。
- 工作台采用单一输入面板，学习库改为封面与标题主导。文章使用开放的阅读版式，音频使用深色播放器区域；图解、关系、练习统一边界与字阶。学习来源、安全提示、实际内容均保留。
- 保留 ReactBits 标题入场、选项切换、封面轻缩放。取消主图鼠标倾斜与无限漂浮；选项波形和节点动画有限次播放。保留减少动态、页面隐藏时暂停以及设置入口。

## 保留边界

8 题问卷、Skill 生成/编辑、单次偏好、七种学习形式、媒体控制、原文锚点、笔记、私有学习库和恢复能力不变。删除的是首页重复说明及视觉结构，不是学习正文或保障数据可用的能力。

历史公开示例页面、既有 MP4、音频和已生成网页动画的内部 HTML 保持原样；本轮统一的是主产品界面与作品外层播放器。不会因为换 UI 覆盖已生成作品。

封面 `public/images/window-cover.jpg` 从本项目服务器原有 `public/demo/zhihu-window-20260908/media/poster.jpg` 原样复制，81,942 字节，非新生图。旧纸带图片保留用于无视频作品的默认封面。

## 验证与发布

使用单元、HTTP、组件服务端渲染、类型、规范、构建及生产 HTML 检查；额外检查无固定侧栏偏移、减少动态及首页真实封面。公网逐项比对生产 JS/CSS 和封面字节。

不执行浏览器截图或点击验收，因此这些检查不等同于浏览器视觉验收。前端独立发布，保留上一版本，不重启 API、不迁移数据库、不改密钥与其他服务。
